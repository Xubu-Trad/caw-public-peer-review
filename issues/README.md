# Review Issues

This directory exists for structured peer-review questions that should be promoted into GitHub issues or tracked as open findings.

Use one file per issue when a finding needs a durable public challenge record.

Each issue file should include:

- claim ID,
- current status,
- exact evidence,
- reproduction command or source path,
- what would falsify or close the finding,
- date and upstream commit reviewed.

Do not use this directory for unsupported motive, identity, or fraud allegations. Those remain unproven unless direct evidence is added.
